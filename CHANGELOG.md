# История изменений

[English → CHANGELOG.en.md](CHANGELOG.en.md)

## 1.2.0
- **Время отклика клавиш в 5 уровней** с описаниями и таймингами из фирменной программы (USB / 2.4G / Bluetooth), время сна и отключение Win, Alt+F4, Alt+Tab средствами самой клавиатуры. Всё отправляется одним блоком настроек (формат восстановлен анализом фирменной программы; на железе ещё не проверен).
- Убраны перехват клавиш на ПК и кнопка синхронизации часов.
- Добавлен готовый **пример анимации на 24 кадра** и кнопка его загрузки на странице «Экран TFT».
- Новый этап активации «Настройки», обновлён «Обзор».
- Байт «standby» у kabelklaus на самом деле — уровень отклика клавиш.

## 1.1.0
- Управление включается одним подтверждением; согласие запоминается, отключается на странице «Безопасность».
- Страница «Клавиатура», 13 пресетов подсветки, генератор анимированных фонов, новая иконка, скрипт ярлыка, одиночный EXE (`Build-Release.ps1`), лицензия MIT, README на двух языках.

## 1.0.0
- GIF/PNG как фон экрана, слой «снимок времени», честные ограничения (нет наложения поверх GIF, нет аналога Fn+Del, приёмник 2.4 GHz только для ввода).
