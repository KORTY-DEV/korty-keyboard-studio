# KORTY Keyboard Studio

**Бесплатное офлайн-приложение для Windows для AJAZZ AK820 Pro:** подсветка RGB, свои картинки и GIF на TFT-экране, время отклика клавиш, сон и отключение клавиш — без фирменной программы.

[English version → README.en.md](README.en.md)

![Обзор](docs/screenshots/01-overview.png)

> Неофициальный проект, не связан с AJAZZ. Работает с клавиатурой по USB HID теми же командами, что и веб-конфигуратор [kabelklaus/ajazz-ak820-pro](https://github.com/kabelklaus/ajazz-ak820-pro). **Используйте на свой риск.** Подтверждено на реальной AK820 Pro в USB-режиме: RGB, загрузка PNG и GIF.

## Возможности

- **Подсветка** — любой цвет (палитра, HSV, HEX, «Мои цвета»), 20 эффектов прошивки, яркость, скорость, направление, готовые пресеты, живой приблизительный предпросмотр (кликайте по клавишам или печатайте).
- **TFT-экран** — редактор слоёв (картинки, GIF, текст), генератор анимированных фонов, предпросмотр «как на экране», библиотека, загрузка PNG и GIF.
- **Настройки клавиатуры** — **время отклика клавиш в 5 уровней** (с таймингами и описаниями из фирменной программы), время сна (никогда / 1 / 5 / 30 мин), отключение Win / Alt+F4 / Alt+Tab **в самой клавиатуре** (работает без запущенной KORTY).
- **Пример анимации** — готовая GIF «KORTY» на 24 кадра (`examples/korty-24frames.gif`, кнопка «Пример: KORTY 24 кадра» на странице экрана) для проверки загрузки.
- **Профили** USB / 2.4 GHz, **диагностика**, без аккаунтов, телеметрии и сети, права администратора не нужны.

## Установка

1. Скачайте ZIP из **Releases**, распакуйте.
2. Запустите `KORTY.KeyboardStudio.exe` (установка .NET не нужна). Ярлык на рабочий стол и в меню «Пуск» — `Create-Shortcut.ps1` (ПКМ → «Выполнить с помощью PowerShell»).
3. Закройте фирменную программу и вкладки веб-конфигураторов.
4. Подключите клавиатуру **кабелем USB-C с данными** в **USB-режиме** — слева появится «USB-C».
5. При первом применении нажмите **«Включить управление клавиатурой»** и подтвердите один раз. До этого ничего не отправляется.

## Как пользоваться

| Что нужно | Где |
|-----------|-----|
| Цвет/эффект | **Подсветка** → пресет/эффект/цвет → «Применить к клавиатуре» |
| Картинка или GIF на экран | **Экран TFT** → «＋ Фото/GIF» (или «Создать фон») → «Подготовить план» → «Отправить на экран». Начинайте с коротких GIF (до 10 кадров) |
| Вернуть свою GIF после отключения питания | **Fn + Del** на клавиатуре (переключает заводской экран и вашу GIF) |
| Время отклика / сон / отключение клавиш | страница **Клавиатура** (для первой проверки примените те же значения, что сейчас в фирменной программе) |

Всё, что отправлено на клавиатуру, **хранится в ней**; программа потом не нужна. **Автозапуск не нужен**.

## Ограничения прошивки (честно)

- **Нет часов, заряда и значка подключения поверх вашей GIF** — такой команды в протоколе нет; часы показывает заводской экран. «Снимок времени» в картинке статичен.
- **Программного аналога Fn+Del не найдено**; неизвестные команды KORTY не пробует.
- **Приёмник 2.4 GHz — только ввод**: подсветку и экран по воздуху менять нельзя.
- **Блок настроек (отклик клавиш, сон, отключение клавиш) на железе ещё не подтверждён.** Раскладка байтов восстановлена статическим анализом фирменной программы (ничего не запускалось), см. docs/PROTOCOL_RESEARCH.md. Веб-конфигуратор kabelklaus называет этот байт «standby», а по фирменной программе это уровень отклика клавиш.
- Синхронизация часов не предлагается (на часы заводского экрана не делаем упор).
- Частота опроса, сброс и заводской сброс сознательно не предлагаются.

## Безопасность

Запись возможна только после включения управления и только на устройство **VID 0C45 / PID 8009** с точным совпадением HID-дескрипторов (`FF13`, feature 65 Б; `FF68`, output 4097 Б). Каждая команда проверяется по фиксированному списку; сброс, перепрошивка, ремап, макросы, частота опроса и неизвестные команды заблокированы навсегда. Другие ревизии клавиатуры отклоняются, а не угадываются. Подробнее: [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md).

## Как помочь

- **Отчёты о совместимости** — «Диагностика → Экспорт отчёта» (без серийных номеров и путей устройств) приложите к issue, если клавиатура не распознана.
- **Результат проверки страницы «Клавиатура»** — напишите в issue, сработали ли отклик клавиш, сон и отключение клавиш на вашей клавиатуре.
- **Другие настройки** — запишите USB-трафик фирменной программы (USBPcap + Wireshark) и приложите `.pcapng`; публикуйте только то, чем готовы поделиться.
